Parameter Optimization Reference Guide

λ¹ · L1 Loss (Pixel-level Reconstruction)

Enforces absolute temperature calibration. If too low (< 5), the model outputs physically inaccurate temperatures. If too high (> 15), outputs become blurry averages of the dataset.

λ² · L_VGG Loss (Perceptual Detail)

Measures structural texture alignment using pre-trained VGG-19 conv3_3 features. Keeps visual elements looking structurally cohesive rather than disjointed pixels.

λ³ · L_GAN Loss (Adversarial Realism)

Forces the Generator to synthesize high-frequency surface textures (like agricultural lines or concrete grids) by competing with the PatchGAN discriminator.

λ&sup4; · L_SEM Loss (Lovász Semantic Guard)

Uses the ESA land cover labels to penalize temperature bleeding across logical borders (e.g. preventing cold water temperatures from leaking into adjacent warm barrens).

Integrated Storage & Database Architecture

Modular caching and persistence configuration optimized for large multispectral rasters.

🗂️
Object Storage
AWS S3 / Azure Blobs
Stores raw multi-band TIFFs and model parameters (.pt). Dataloaders leverage streaming COGs (Cloud Optimized GeoTIFFs) to load patches asynchronously on the fly.
🗃️
SQL Database
Supabase Postgres / SQLite
Saves processing logs, NDVI/NDWI telemetry indexes, and YOLO classification results (coordinate bounds). Built-in SQLAlchemy engine switches automatically.
⚡
In-Memory Cache
Redis Cloud / Local Upstash
Caches processed image buffers using MD5 payload checksums as cache keys. Cuts colorization response times from ~3s to sub-5 milliseconds for repeat tiles.

Technical Glossary & Definitions

Key deep learning and remote sensing terms. Hover over terms across the dashboard to trigger definitions dynamically.

GAN

A neural framework where a Generator synthesizes realistic outputs (e.g. converting single-band thermal into optical RGB) and a Discriminator tries to distinguish generated imagery from real targets.

Super-Resolution

The process of increasing the spatial resolution of an image by reconstructing high-frequency details. In this project, upscaling the coarse 200m downsampled Thermal Infrared (TIR) input back to a sharp 100m native equivalent.

Lovász-Softmax

A specialized loss function that directly optimizes the Intersection-over-Union (IoU) segmentation metric. Ensures sharp borders between geographic segments (like urban buildings and water bodies).

PatchGAN

A discriminator architecture that classifies N x N local patches in an image rather than producing a single global score, preserving sharp high-frequency textures.

NDVI

Normalized Difference Vegetation Index. A standardized index to measure green vegetation density, calculated from Red and Near-Infrared bands.

NDWI

Normalized Difference Water Index. A satellite index used to monitor changes in surface water bodies and moisture levels, calculated from Green and Near-Infrared bands.

MOSDAC

Meteorological and Oceanographic Satellite Data Archival Centre. ISRO's data portal responsible for archiving weather and climate satellite data, including INSAT-3D/3DR collections.

USGS

United States Geological Survey. The primary scientific agency of the United States, providing the official Landsat satellite data catalog.
